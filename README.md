# Spotify Music Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on Spotify music data.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Features
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Interactive Dashboard

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
